# 過去バージョンについて

ここには、各メジャーバージョンの最終版を参照用に残しています。内容は更新されません。最新版は [CODE v5.0](/code/) をご覧ください。

| バージョン | 概要 | 文書 |
| --- | --- | --- |
| [v4.3](./v4.3/) | Project Sprint がこれまでも重視してきた「作成物を生む」という行為により重点を置き、プロジェクトを「出力」と「成果」の関係から捉えなおした。 | Introduction / Definitions / Framework |
| [v3.3](./v3.3/) | プロジェクトのすべての要素はプロジェクトチームによって規定されるものであるという思想に基づき、プロジェクトチームを主体とする記述に全面アップデート。 | Theories / Practices / Essentials / Reference |
| [v2.2](./v2.2/) | 読みやすさ・使いやすさを考え、各種ドキュメント体系を再構築。 | Tutorial / Essentials / Tips / Advance / Reference |

## 英語版について

英語版は右上の言語切り替えから [English](/en/) をご覧ください。現在は v2.0 の英語版のみ公開しており、v5 の英訳を計画しています。

## 掲載していないマイナーバージョンについて

v4.0〜v4.2、v3.0〜v3.2 などのマイナーバージョンは、このサイトには掲載していません。各バージョンの変更内容は [Release Notes](/releases) を、文書そのものは GitHub リポジトリの履歴（[v4.3-transition](https://github.com/ProjectSprintOrg/projectsprint.org/releases/tag/v4.3-transition) 以前のコミット）をご参照ください。

## Practical Guide について

現行の [Practical Guide](/practical-guide/) は CODE v4 準拠です。CODE v5 に準拠した版が公開された時点で、v4 準拠版はこのアーカイブへ移します。
