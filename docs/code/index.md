# CODE とは

**CODE** とは、Project Sprint について説明した文書群の総称です。Project Sprint の考え方と構造を言語化したもので、Workshop での体験に意味を与え、実践における判断の基準を与えることを役割としています。

## v5.0（最新版）

v5 では、Project Sprint を単なるプロジェクト推進手法としてではなく、不確実な状況の中で価値を探索しつづけるためのフレームワークとして再整理しました。探索と収束、多様な個人と共通了解、価値の湧現といった観点から、Project Sprint の背景にある世界観・構造・態度を体系的に記述しています。

CODE は、理解の進度と、その先の実践の難度に応じて、3 つのステップに分かれています。

| 文書 | 内容 |
| --- | --- |
| [Introduction](./introduction) | まずは Project Sprint の全体像を把握しよう |
| [Step0. 個人が世界を更新する](./step0) | 個人としてどのように探索に参加するかを理解しよう |
| [Step1. 他者と世界の認識を分かち合う](./step1) | チームとしてどのように探索を進めるかを理解しよう |
| Step2. 世界に価値が立ち上がる | v5.1 以降で記述予定 |
| [Key Terms](./keyterms) | 主要な用語の定義を確認しよう |

## 読む順序

Project Sprint 未体験の方は、[Workshop](/workshop/) を体験したあとに読み始めることをおすすめします。読み終えたら、[Practical Guide](/practical-guide/) で実際のプロジェクトへの適用に進んでください。
