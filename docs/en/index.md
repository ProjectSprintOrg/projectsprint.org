# Project Sprint

Project Sprint is an open-source framework for moving projects forward under uncertainty.

It treats a project not as the execution of a predefined answer, but as an activity that updates understanding through action and explores value. Through a rhythm of exploration and convergence, it integrates the actions of diverse individuals into a team and connects them to the realization of value.
