# CODE

**CODE** is the collective name for the body of documents that describe Project Sprint. It puts the thinking and structure of Project Sprint into words. Its role is to give meaning to the experience of the Workshop, and to provide criteria for judgment in practice.

## v5.0 (current)

In v5, Project Sprint was reorganized not merely as a method for running projects, but as a framework for continuing to explore value amid uncertainty. From the viewpoints of exploration and convergence, diverse individuals and shared understanding, and the emergence of value, it systematically describes the worldview, structure, and attitudes behind Project Sprint.

CODE is divided into three Steps, according to the stage of understanding and the difficulty of the practice that follows.

| Document | What it is for |
| --- | --- |
| [Introduction](./introduction) | Start here to grasp the overall picture of Project Sprint |
| [Step0. The Individual Updates the World](./step0) | Understand how to take part in exploration as an individual |
| [Step1. Sharing Our Perception of the World with Others](./step1) | Understand how to carry exploration forward as a team |
| Step2. Value Emerges in the World | To be written in v5.1 or later |
| [Key Terms](./keyterms) | Check the definitions of the main terms |

## Reading order

## About this translation

This English edition is an AI-assisted translation of the Japanese original, reviewed by the Project Sprint community. The Japanese text is the authoritative version. See the note at the top of each page, and the [Key Terms](./keyterms) page for how a few central Japanese terms were rendered.
