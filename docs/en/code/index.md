# CODE

**CODE** is the collective name for the body of documents that describe Project Sprint. It puts the thinking and structure of Project Sprint into words. Its role is to help you make sense of what you experienced in the Workshop, and to give you criteria for judgment in practice.

## v5.0 (Current)

In v5, Project Sprint was reorganized not merely as a method for running projects, but as a framework for continuing to explore value amid uncertainty. Through three lenses (exploration and convergence; diverse individuals and shared understanding; the emergence of value), CODE systematically describes the worldview, structure, and attitudes behind Project Sprint.

CODE is divided into three Steps, ordered by the depth of understanding each requires and by the difficulty of the practice it leads to.

| Document | What it is for |
| --- | --- |
| [Introduction](./introduction) | Start here to grasp the overall picture of Project Sprint |
| [Step0. The Individual Updates the World](./step0) | Understand how to take part in exploration as an individual |
| [Step1. Sharing Our Perception of the World with Others](./step1) | Understand how to carry exploration forward as a team |
| Step2. Value Emerges in the World | To be written in v5.1 or later |
| [Key Terms](./keyterms) | Check the definitions of the main terms |

## Reading Order

If you have not yet experienced Project Sprint, we recommend going through the [Workshop](https://gemini.google.com/gem/1sSD-IgnFHhASaWH52fsn3dHWkyMg9J9L?usp=sharing) first. The Workshop is currently available in Japanese only. After reading CODE, continue to the Practical Guide (currently Japanese only) to apply Project Sprint to a real project.
